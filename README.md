# Advanced E-commerce Demo

This is a self-contained static demo that showcases an advanced e-commerce UI with:

- Product grid, search, filters and sorting
- Product detail modal
- Cart with quantity controls and localStorage persistence
- Mock checkout flow

To run locally:

1. Open [index.html](index.html) in your browser.
2. Interact with products, add to cart, and press Checkout.

No build tools are required.
